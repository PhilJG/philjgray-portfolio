# Neuroprojection Media Files

Place the following image files in this directory:

## Required Files:

1. **hero.jpg** - Hero image for the project detail page (recommended: 1920x1080 or larger)
2. **gallery-1.jpg** - Gallery image 1
3. **gallery-2.jpg** - Gallery image 2
4. **gallery-3.jpg** - Gallery image 3
5. **gallery-4.jpg** - Gallery image 4
6. **og-image.jpg** - Open Graph image for social sharing (recommended: 1200x630)

All images should be optimized for web (WebP format recommended, but JPG is also fine).
